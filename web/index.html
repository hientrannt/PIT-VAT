Tập hợp & tính thuế Hộ kinh doanh

Kéo-thả các file xuất từ phần mềm (nhiều file cùng loại cũng được). Trang tự nhận diện, gộp và tính thuế GTGT 1% + TNCN 0,5%. Dữ liệu chỉ xử lý trong trình duyệt của bạn, không gửi đi đâu.

1Chọn file

Kéo-thả file vào đây hoặc

Đang hiển thị dữ liệu mẫu để bạn xem trang hoạt động thế nào. Thêm file của bạn, dữ liệu mẫu sẽ tự bỏ đi.
